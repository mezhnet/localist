# Subnetting

Ein Subnetz teilt ein Netzwerk in **kleinere Bereiche**.

> [!tip] Merksatz
> Je größer das Präfix, desto kleiner das Netz.

## Beispiele

| Präfix | Adressen |
|---|---|
| /24 | 256 |
| /25 | 128 |
| /26 | 64 |

- [x] Präfixe verstehen
- [ ] Übungsaufgaben rechnen

> [!note]- Lösungsweg
> 2 hoch (32 − Präfix) ergibt die Zahl der Adressen.
